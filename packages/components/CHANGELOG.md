# @fast/components

## 1.8.0

### Minor Changes

- Add `FastSegmentedToggle`: generic N-option segmented control with a sliding thumb, icons/labels, roving tabindex and arrow-key navigation.
- Add `FastTour`: config-driven guided tour with spotlight cutout, auto card placement, keyboard navigation, localStorage auto-start/replay and `onStepEnter`/`onStepExit` hooks. Steps are passed in by the host app (`FastTourStep[]` + `storageKey`), so each app keeps its own tour config file.
